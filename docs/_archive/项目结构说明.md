## 🔧 配置说明

### 环境变量(config/.env)

```env
# MiniMax(默认,推荐)
MINIMAX_API_URL=https://api.minimax.chat/v1
MINIMAX_API_KEY=your_api_key
MINIMAX_GROUP_ID=your_group_id
MINIMAX_MODEL_NAME=MiniMax-Text-01
MINIMAX_TTS_MODEL=speech-2.8-hd

# 讯飞(备选)
XUNFEI_API_URL=https://maas-coding-api.cn-huabei-1.xf-yun.com/v2/chat/completions
XUNFEI_API_KEY=your_xunfei_api_key
MODEL_NAME=astron-code-latest

# 数据库
DATABASE_URL=mysql+aiomysql://user:password@host:port/xingshi
DATABASE_URL_SYNC=mysql+pymysql://user:password@host:port/xingshi

# 调试
APP_DEBUG=False
XINGSHI_DEBUG=False
```

### 数据库

- **MySQL**:运行 `python Navicat/setup_database.py --backend=mysql`
- **SQLite**(默认):运行 `python Navicat/setup_database.py --backend=sqlite`
- 详见 [部署文档.md §4](部署文档.md#四数据库初始化详解)


## 🗂️ 各模块详细说明

### 智能体架构(agents.py)

- `MasterController` - 主控智能体,协调所有子智能体
- `ProfilerAgent` - 学情分析(6 维画像 / 情绪识别 / 盲区检测)
- `PlannerAgent` - 学习路径规划(知识图谱 / 内容路由)
- `SocraticEvaluatorAgent` - 苏格拉底式教学(强度可配)
- `DocumentGeneratorAgent` - 文档生成
- `MindmapGeneratorAgent` - 思维导图生成
- `ExerciseGeneratorAgent` - 练习题生成
- `VideoContentAgent` - 视频内容生成
- `ResourcePushAgent` - 资源推送
- `EvaluationAgent` - 学习效果评估
- `EchoAgent` - 记忆回响
- `FlashcardAgent` - 闪卡生成

### 教学引擎(app/services/tutor_engine/)

- `pipeline_gate.py` - 4 层管线(L0 输入安全 / L1 意图路由 / L2 苏格拉底 / L3 输出脱敏)
- `hallucination_guard.py` - 4 级防幻觉(L1 引用 / L2 Web 交叉 / L3 沙箱 / L4 置信度)
- `proactive_advisor.py` - 25+ 主动干预规则
- `context_aggregator.py` - 上下文聚合

### 服务层(app/services/)

详见 [§5 服务层](#5️⃣-服务层appservices) 表格。
