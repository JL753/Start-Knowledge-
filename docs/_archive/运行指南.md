## 📋 项目简介

星识 (Star-Learn) 是一个基于多智能体架构的智能教学辅助系统,为学生提供个性化的学习体验。支持智能对话、苏格拉底式教学、代码练习、学习路径规划等功能。

## 🚀 安装步骤

### 1. 克隆项目

```bash
git clone <项目地址>
cd xingshi
```

### 2. 安装 Python 依赖

```bash
pip install -r requirements.txt
```

主要依赖:

- `fastapi` - Web 框架
- `uvicorn` - ASGI 服务器
- `pydantic` - 数据验证
- `sqlalchemy` + `alembic` - ORM + 迁移
- `aiosqlite` / `aiomysql` - 异步数据库驱动
- `python-pptx` - PPT 处理

### 3. 配置环境变量

```bash
cp config/.env.example config/.env
```

编辑 `config/.env`,至少填入一组 LLM 凭证(选其一):

```env
# === 方案 A:MiniMax(默认,推荐) ===
MINIMAX_API_URL=https://api.minimax.chat/v1
MINIMAX_API_KEY=your_minimax_api_key
MINIMAX_GROUP_ID=your_group_id
MINIMAX_MODEL_NAME=MiniMax-Text-01

# === 方案 B:讯飞大模型(备选) ===
XUNFEI_API_URL=https://maas-coding-api.cn-huabei-1.xf-yun.com/v2/chat/completions
XUNFEI_API_KEY=your_xunfei_api_key
MODEL_NAME=astron-code-latest

# 通用
APP_DEBUG=False   # 开发时设为 True
```

> **获取 API Key**:
> - MiniMax → 访问 [MiniMax 控制台](https://api.minimax.chat)
> - 讯飞 → 访问 [讯飞开放平台](https://console.xfyun.cn/)

### 4. 初始化数据库

**方式 A:SQLite(推荐本地开发)**

```bash
python Navicat/setup_database.py --backend=sqlite
```

无需任何外部依赖,数据库文件创建于 `xingshi_v2.db`。

**方式 B:MySQL(适合生产 / 多人协作)**

确保 MySQL 服务正在运行,然后执行:

```bash
export MYSQL_HOST=127.0.0.1
export MYSQL_PORT=3306
export MYSQL_USER=root
export MYSQL_PASSWORD=your_password
python Navicat/setup_database.py --backend=mysql
```

脚本会创建数据库 `xingshi` + 全部 35 张表(幂等)。

## ▶️ 启动项目

### 方式一:推荐启动脚本

```bash
python main.py
```

### 方式二:Uvicorn(开发模式,热重载)

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

参数说明:

- `--reload`:开发模式,代码改动自动重启
- `--host 0.0.0.0`:允许外部访问
- `--port 8000`:默认端口

### 访问地址

启动成功后,打开浏览器访问:

| 地址 | 说明 |
|------|------|
| http://127.0.0.1:8000 | 主页面 |
| http://127.0.0.1:8000/docs | API 文档(Swagger UI) |

## 🎬 预置 Demo 内容

首次启动后,应用会自动从 `storage/seed/demo/` 加载演示内容,无需任何手动操作:

- **5 门演示课程**(Python / Web 前端 / 数据结构与算法 / AI 导论 / 线性代数)
- **对应课堂**(每门课程的 PPT)
- **可见用户**:所有用户(含未登录)

如需修改 / 升级 Demo 内容:

1. 编辑 `storage/seed/demo/*.json`
2. 在 `manifest.json` 里 bump `demo_version`(如 `2.0.0` → `2.0.1`)
3. 下次启动自动替换 demo 内容;用户私有数据完全不受影响

```bash
# 手动重置
python scripts/seed_demo.py --reset
# 查看当前状态
python scripts/seed_demo.py --check
```

详见 [演示内容注入执行报告.md](演示内容注入执行报告.md) 与 `storage/seed/demo/README.md`。

## 🛠️ 开发指南

### 运行开发服务器(热重载)

```bash
uvicorn main:app --reload --port 8000
```

修改代码后会自动重载。

### 运行测试

```bash
# 后端单元测试
pytest tests/

# 前端单元测试
npm install
npm run test:unit

# 前端 E2E 测试(需先启动应用)
npm run test:e2e
```

### 数据库迁移(使用 Alembic)

```bash
# 创建迁移
alembic revision --autogenerate -m "描述"

# 执行迁移
alembic upgrade head

# 回滚一个版本
alembic downgrade -1
```

### 启动 Agent 编排控制塔

前端 `html/index.html#track-a` 实时呈现 10 个 Agent 的协作。

启动步骤:

1. 启动 FastAPI:`uvicorn main:app --reload`
2. 打开浏览器:http://localhost:8000/html/index.html
3. 左侧 `🛰 Agent 编排控制塔` 有 3 个按钮:`⏸` `⏹` `▶ 启动协作`
4. 点击 `▶ 启动协作` → 后端 `MasterController.execute()` 走 SSE
5. 观察 6 维雷达 + 4 张画像小卡应实时变化(800ms 缓动)

### 5 身份差异化苏格拉底

`app/services/teacher/personas.py` 中 5 个 persona 的 `socratic_intensity`:

| persona | name | socratic_intensity | 行为 |
|---------|------|--------------------|------|
| patient_tutor | 陈默 | 0.4 | 基础直讲,进阶给跳板 |
| socratic_questioner | 林问 | 1.0 | 纯反问 |
| energetic_lecturer | 周燃 | 0.1 | 几乎不反问 |
| expert_mentor | 严铮 | 0.7 | 基础直讲,进阶反问 |
| caring_counselor | 苏语 | 0.0 | 0 苏格拉底(情绪场景) |

切换身份:点击教师卡 → 5 头像浮窗 → 选一个。`build_system_prompt` 会按强度注入对应规则。

## 🆘 常见问题

### 1. 启动报错 "Module not found"

```bash
pip install -r requirements.txt
```

### 2. 数据库连接失败

- 检查 MySQL 服务是否运行
- 确认用户名、密码、端口配置正确
- 或切换到 SQLite:`python Navicat/setup_database.py --backend=sqlite`

### 3. LLM API 调用失败

- 检查 `MINIMAX_API_KEY` / `XUNFEI_API_KEY` 是否正确
- 检查网络能否访问对应 API
- 确认 API 额度充足

### 4. CORS 跨域问题

项目已配置允许所有来源的 CORS,如需限制,修改 `main.py` 中的:

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],  # 改为你的前端地址
    ...
)
```

### 5. SSE 流断开

- Nginx 必须设置 `proxy_buffering off`
- 检查 `proxy_read_timeout` ≥ 3600s

### 6. 静态资源 404

检查 Nginx `location` 路径与文件实际位置一致。

更多故障排查:[部署文档.md §9](部署文档.md#九常见问题排查)
